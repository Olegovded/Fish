# Запуск приложения — простая инструкция

Делаем два шага: **1) постоянная база (Supabase)** — чтобы уловы не терялись,
**2) хостинг (Render)** — чтобы приложение работало и само привязалось к боту.

Всё бесплатно. От вас — только скопировать/вставить несколько строк. Ничего
устанавливать на компьютер не надо.

Держите под рукой:
- **токен бота** от @BotFather (у нас уже есть);
- 15 минут времени.

---

## Шаг 1. База данных Supabase (чтобы данные хранились всегда)

1. Откройте **https://supabase.com** → **Start your project** → войдите (удобно
   через GitHub).
2. **New project**. Задайте:
   - **Name** — любое, например `ribaku`.
   - **Database Password** — придумайте пароль и **запишите его** (пригодится).
   - **Region** — выберите поближе (например, Frankfurt).
   - Нажмите **Create new project**, подождите ~2 минуты, пока создаётся.
3. Слева нажмите шестерёнку **Project Settings → Database**.
4. Найдите блок **Connection string**, вкладка **URI**. Там строка вида:
   ```
   postgresql://postgres:[YOUR-PASSWORD]@db.xxxxxxxx.supabase.co:5432/postgres
   ```
   **Скопируйте её** и замените `[YOUR-PASSWORD]` на пароль из пункта 2.
   Это и есть ваша строка подключения — назовём её **DATABASE_URL**. Сохраните
   её в заметки, понадобится на шаге 2.

> Таблицы создавать вручную не нужно — приложение создаст их само при первом
> запуске.

---

## Шаг 2. Хостинг Render (запуск + привязка к боту)

1. Откройте **https://render.com** → **Get Started** → войдите через GitHub.
2. Сверху **New +** → **Blueprint**.
3. Выберите репозиторий **`Olegovded/Fish`**. Если его нет в списке — нажмите
   **Configure account / Connect GitHub** и дайте доступ к репозиторию.
4. Выберите ветку **`claude/telegram-fishing-bot-mvp-27rotr`**. Render увидит
   файл `render.yaml` и покажет сервис `ribaku-bot`.
5. Он попросит заполнить два секрета:
   - **BOT_TOKEN** — вставьте токен от @BotFather.
   - **DATABASE_URL** — вставьте строку из Шага 1 (с вашим паролем внутри).
6. Нажмите **Apply** (или **Create**). Render соберёт и запустит приложение —
   это ~2–4 минуты. Дождитесь статуса **Live**.
7. **Готово.** Приложение само привяжет кнопку меню к боту.
   Откройте в Telegram **@Ribaku_bot** → снизу кнопка **«🎣 Открыть»**, либо
   напишите боту **/start** и нажмите кнопку. Записывайте улов!

Проверка, что живо: откройте в браузере `https://<адрес-сервиса>/health` —
должно показать `{"ok": true}` (адрес виден в панели Render, вида
`https://ribaku-bot.onrender.com`).

## Если что-то не так

- **Бот не отвечает на /start** — подождите 30–40 секунд (на бесплатном тарифе
  сервис «просыпается» после простоя) и напишите /start ещё раз.
- **Кнопки «Открыть» нет** — в панели Render откройте вкладку **Logs**: должна
  быть строка «Кнопка меню привязана к …». Если её нет — проверьте, что задан
  BOT_TOKEN. Сделайте **Manual Deploy → Deploy latest commit**.
- **Данные пропадают** — значит не подхватился DATABASE_URL (приложение ушло на
  временную SQLite). В логах при старте должно быть «База данных:
  Postgres/Supabase». Проверьте, что DATABASE_URL задан и пароль в нём верный.
- **Ошибка подключения к базе** — чаще всего неверный пароль в DATABASE_URL или
  лишние пробелы. Скопируйте строку заново из Supabase и подставьте пароль.

  же: `BOT_TOKEN`, `BOT_USERNAME`, `DATABASE_URL`, `WEBAPP_URL`.
- **Свой VPS** — домен + Nginx + HTTPS + systemd (`deploy/fishing-bot.service`).
  Напишите — распишу под вашего провайдера.
