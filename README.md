# 🎣 Рыбаки — Telegram mini app (дневник улова)

Мини-приложение внутри Telegram (@Ribaku_bot): рыбак записывает улов, видит свои
рекорды, прогноз клёва и соревнуется с друзьями. Данные копятся в единой базе —
это основа для будущих инсайтов и сообщества («цепочка рыбаков»).

## Что уже работает

- **Профиль рыбака** — старт приложения: статистика (рыб, кг, поездки), уровень,
  крупная кнопка «Записать улов».
- **Запись улова** — несколько видов за раз, у каждого: количество, общий вес,
  **вес самой крупной особи** (идёт в личный рекорд по виду) и **несколько
  наживок**. Есть «+ Свой вид» и «+ Своё» (своя наживка). Пустой день тоже
  фиксируется.
- **Прогноз клёва** — балл дня (1–10) и лучшие часы по солнечно-лунной теории
  (solunar), считается локально по геолокации. Без нейросетей и внешних сайтов.
  Погода (Open-Meteo) — справкой рядом.
- **Личные рекорды** по каждому виду (вес крупнейшей особи).
- **Лента** уловов сообщества, **рейтинг** по весу, **«Пригласить друга»**.
- **Поделиться уловом** — готовое сообщение (бриф + ссылка) в любой чат Telegram
  через нативный шеринг (сарафанный рост).
- **Фото** — хранит сам Telegram (мы держим только `file_id`), своё хранилище
  не нужно. *(включается на следующем шаге)*

Локация всегда округляется до **зоны сетки** (~1 км) — точный пин не хранится.

## Архитектура

Один процесс на aiogram + aiohttp:

```
bot/
  main.py            вход: бот (self-bind кнопки меню) + веб-сервер
  config.py          конфиг из окружения (+ RENDER_EXTERNAL_URL)
  webapp/
    server.py        раздаёт мини-апп + API (/api/me, /report, /feed, /rank, /forecast)
    store.py         база уловов (SQLite): users, reports, items; рекорды по видам
    static/index.html  само мини-приложение (Telegram WebApp SDK)
  services/
    solunar.py       прогноз клёва (положение Луны/Солнца)
    weather.py       погода Open-Meteo (бесплатно, без ключа)
    moon.py, geo.py  фаза луны, зона сетки
mockups/miniapp.html кликабельный прототип интерфейса (для обсуждения)
docs/
  deploy.md          деплой и привязка к боту
  pricing.md         стоимость на клиента и роадмап
```

Личность пользователя берётся из подписанного Telegram `initData` и проверяется
по HMAC на каждом запросе.

## Запуск / деплой

Приложение само привязывает кнопку меню к боту при старте. Разворачивается на
бесплатном хостинге в несколько кликов — см. **[docs/deploy.md](docs/deploy.md)**
(рекомендуется Render.com; есть Dockerfile и вариант для VPS).

Локально (нужен публичный HTTPS для WebApp, напр. через `cloudflared`):
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # BOT_TOKEN, BOT_USERNAME, WEBAPP_URL
python -m bot.main
```
