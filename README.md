# 🎣 Дневник рыбака — Telegram-бот (MVP)

Telegram-бот для рыбаков: быстрый структурированный отчёт об улове, автоподтяжка
погоды и фазы луны, личный дневник, статистика по зоне и карточка для шеринга.
Локация всегда округляется до зоны (~1 км) — точный пин не сохраняется.

Это **MVP** для проверки гипотезы: будут ли люди регулярно логировать уловы и
появится ли от этого польза — сначала лично, потом на уровне сообщества.

## Что уже умеет (MVP)

- 🎣 **Быстрый отчёт**: поймал/не поймал → вид рыбы → наживка/снасть → комментарий
  → фото. Везде кнопки, свободный текст — только по кнопке «Своё». Последний
  выбор запоминается и предлагается первым (минимум тапов).
- 🌤 **Погода и фаза луны** подтягиваются автоматически на дату/место отчёта.
  Погода — [Open-Meteo](https://open-meteo.com) (бесплатно, без ключа); фаза луны
  считается локально.
- 📖 **Личный дневник** — история своих отчётов. Работает без чужих данных
  (решает холодный старт).
- 📊 **Статистика зоны** — сколько отчётов за 2 недели, % с уловом, топ видов.
  Сырые цифры, без алгоритма доверия. Нет данных — так и говорим.
- 🗺 **Мини-приложение с картой** (Telegram WebApp) — свои точки на карте
  (Leaflet + OpenStreetMap). Опционально, включается через `WEBAPP_URL`.
- 🔗 **Карточка шеринга** с водяным знаком бота и deep-link «открыть в боте» —
  встроенный канал роста.

## Архитектура

Единая база отчётов (SQLite) — фундамент, поверх которого живут бот и
мини-приложение. При портировании на MAX меняется только слой интеграции с
мессенджером, структура данных сохраняется.

```
bot/
  main.py            вход: polling + веб-сервер мини-приложения
  config.py          конфиг из окружения
  db.py              SQLite: users, reports, user_prefs
  handlers/          сценарии: start, report (FSM), diary, stats
  services/          weather (Open-Meteo), moon, geo (сетка/зоны),
                     catalog (виды/наживки), keyboards, share
  webapp/            aiohttp-сервер + static/index.html (карта на Leaflet)
docs/
  pricing.md         стоимость на клиента и пути развития с ценами
```

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Подготовьте окружение:
   ```bash
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env      # впишите BOT_TOKEN и BOT_USERNAME
   ```
3. Запустите:
   ```bash
   python -m bot.main
   ```

Мини-приложение (карта) требует публичный HTTPS-URL — для MVP можно оставить
`WEBAPP_URL` пустым, тогда дневник отдаётся списком в чате. Для теста карты
поднимите туннель (например, `cloudflared`/`ngrok`) на `WEB_PORT` и укажите
его https-адрес в `WEBAPP_URL`.

Разбор стоимости на каждого клиента в зависимости от функций и поэтапный

## Отложено на после проверки гипотезы

Система доверия/весов (антифейк), ИИ-чат-ассистент (только по реальным данным),
карта с фильтром по видам рыб, слои приватности («цепочка» доверенных),
справочник фактов. Архитектура уже заложена так, чтобы добавлять их без
переделки (зона вместо пина, единая БД, поле фото).
